# Troubleshooting Guide

## App Building But Not Opening

### Common Symptoms

- `npm run dev` exits with code 1
- Build process completes but Electron window doesn't appear
- App appears in dock/taskbar but no visible window
- Console shows "ready-to-show" but window not displayed

### Diagnostic Steps

#### 1. Check Build Output

```bash
# Ensure all builds complete successfully
npm run build:web
npm run build:app

# Verify output files exist
ls -la dist-react/
ls -la dist-app/
```

**Expected files:**

- `dist-react/index.html`
- `dist-react/assets/`
- `dist-app/main.js`
- `dist-app/preload.js`

#### 2. Verify File Paths

Check that [main.ts](../src/electron/main.ts#L32) loads the correct HTML file:

```typescript
mainWindow.loadFile(path.join(__dirname, "../dist-react/index.html"));
```

**Common Issues:**

- Incorrect relative path to React build
- HTML file not generated by Vite build
- Path resolution issues with ES modules

#### 3. Check Console Output

Run with verbose logging:

```bash
# Enable Electron logging
DEBUG=* npm run dev:app

# Or check renderer process console
npm run dev:web  # Open in browser to test React app separately
```

### Specific Fixes

#### Fix 1: BrowserRouter Issue

**Problem:** React Router BrowserRouter doesn't work well with `file://` protocol

**Solution:** Switch to HashRouter

```tsx
// In src/ui/main.tsx
import { HashRouter } from "react-router-dom";

createRoot(document.getElementById("root")!).render(
  <HashRouter>
    <App />
  </HashRouter>
);
```

#### Fix 2: Build Order Dependencies

**Problem:** Electron starts before React build completes

**Solution:** Ensure build order in package.json

```json
{
  "scripts": {
    "dev": "npm run build && npm run dev:app",
    "build": "npm run build:web && npm run build:app"
  }
}
```

#### Fix 3: TypeScript Module Resolution

**Problem:** ES modules not resolving correctly

**Solution:** Check tsconfig.json module settings

```json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "bundler",
    "allowSyntheticDefaultImports": true
  }
}
```

#### Fix 4: Missing Preload Script

**Problem:** IPC communication fails, window.nav undefined

**Solution:** Verify preload script path in [main.ts](../src/electron/main.ts#L23)

```typescript
webPreferences: {
  preload: path.join(__dirname, "preload.js"), // Ensure correct path
},
```

#### Fix 5: Window Creation Timing

**Problem:** Window created before app is ready

**Solution:** Ensure proper app ready handling

```typescript
app.whenReady().then(() => {
  createWindow(); // Only create window after app is ready
});
```

### Development Debugging

#### Enable DevTools

Add to [main.ts](../src/electron/main.ts) for debugging:

```typescript
mainWindow.webContents.openDevTools();
```

#### Check IPC Communication

Test in DevTools console:

```javascript
// Test navigation
window.nav.to("/settings");

// Test other IPC functions
window.qluely.echo("test");
```

#### Verify React Router

In browser console:

```javascript
// Check current route
console.log(window.location.pathname);

// Test navigation
import { useNavigate } from "react-router-dom";
const navigate = useNavigate();
navigate("/settings");
```

### Platform-Specific Issues

#### macOS

- App might be hidden behind other windows
- Check if dock icon appears
- Verify app doesn't exit immediately due to dock.hide()

#### Windows

- Check Windows Defender/antivirus blocking
- Verify FFmpeg dependencies installed
- Check electron-builder permissions

#### Linux

- Install required system dependencies
- Check wayland vs X11 compatibility
- Verify audio capture permissions

### Performance Issues

#### Slow Startup

1. **Check dependency loading**

   - Large node_modules in bundled app
   - Heavy imports in main process

2. **Optimize preload script**

   - Minimize preload functionality
   - Lazy load heavy operations

3. **React bundle size**
   ```bash
   npm run build:web
   du -h dist-react/assets/*
   ```

### Common Error Messages

#### "Failed to load resource: net::ERR_FILE_NOT_FOUND"

- HTML file path incorrect
- Assets not built correctly
- Base URL configuration issue

#### "Cannot read properties of undefined (reading 'to')"

- Preload script not loaded
- Context bridge not working
- IPC setup incomplete

#### "Module not found: react-router-dom"

- Dependency not installed
- Version compatibility issue
- Build process failed

### Recovery Steps

#### Clean Build

```bash
# Remove all build artifacts
rm -rf dist-react/ dist-app/ node_modules/

# Reinstall dependencies
npm install

# Full rebuild
npm run build
npm run dev
```

#### Reset Electron Cache

```bash
# Clear Electron cache
rm -rf ~/Library/Application\ Support/desktop/  # macOS
rm -rf ~/.cache/desktop/  # Linux
```

### Getting Help

#### Collect Debug Information

1. Node.js version: `node --version`
2. npm version: `npm --version`
3. Electron version: `npx electron --version`
4. Operating system and version
5. Console output with errors
6. Build output logs

#### Report Issues

Include in bug reports:

- Steps to reproduce
- Expected vs actual behavior
- Environment details
- Console logs/error messages
- Minimal reproduction case
